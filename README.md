# Binder Town Manager

ตัวจัดการสำหรับเกม Binder Town: เปิดเกมในเบราว์เซอร์, โหลด helper ให้อัตโนมัติ, ดูสถานะทุกแท็บ และอัปเดตจาก GitHub ผ่านหน้าเว็บ `http://localhost:3889`

## ติดตั้งในเครื่องใหม่

ต้องมี [Node.js](https://nodejs.org/) 22 ขึ้นไป, [Git](https://git-scm.com/) และ Edge / Chrome / Brave / Vivaldi อย่างใดอย่างหนึ่ง

```
git clone https://github.com/chit12121111/binder.git Binder_Town
```

แล้วดับเบิลคลิก `Binder_Town\Start_Binder.bat` (หน้าต่างดำต้องเปิดค้างไว้) เว็บ `http://localhost:3889` จะเปิดขึ้นมาเอง

## ใช้งาน

1. ในเว็บ กด **เปิดเกม** ที่เบราว์เซอร์ที่ต้องการ แต่ละเบราว์เซอร์ใช้โปรไฟล์ของตัวเองในโฟลเดอร์ `profiles/` ล็อกอินครั้งแรกครั้งเดียว
2. เข้าเกมแล้ว helper จะโหลดเองและมีแผง "Binder Helper" ในเกม
3. ยืนที่จุดฟาร์ม กด **จำจุดนี้** แล้วกด **▶** (กดในเกมหรือในเว็บก็ได้)
4. ค่าหัว: กด **🎯 ค่าหัว** ในแผง เลือกตัวที่จะทำ แล้วกดเริ่ม

ตัวละครแบบ guest ผูกกับเบราว์เซอร์ที่สร้าง ถ้าจะใช้ในโปรไฟล์ใหม่ ให้ผูกบัญชี (Google / Discord / ไอดี-รหัสผ่าน) ก่อน

## อัปเดต

เว็บเช็คอัปเดตทุก 10 นาที (หรือกด **เช็คอัปเดต**) ถ้ามี commit ใหม่จะขึ้นปุ่ม **อัปเดต**:

- `git pull --ff-only` แล้วโหลด helper ใหม่ให้ทุกแท็บเกม (สถานะ ▶/■ คงเดิม)
- ถ้าไฟล์ใน `manager/` เปลี่ยน ตัวจัดการจะรีสตาร์ตตัวเอง
- ถ้ามีไฟล์ที่แก้ในเครื่องยังไม่ได้ commit จะไม่อัปเดต (กันไฟล์ทับกัน)

## โครงสร้าง

| โฟลเดอร์ | |
|---|---|
| `helper/binder_helper.js` | ตัว helper ที่โหลดเข้าหน้าเกม |
| `manager/` | เว็บ 3889, เปิดเบราว์เซอร์, โหลด helper, อัปเดต git |
| `tools/` | สคริปต์ dump ข้อมูลเกม (`npm install` แล้ว `node dump.js` → `raw/`, `data/`, `protocol/`) |
| `protocol/` | protocol ของเกมที่แกะไว้ |

`raw/`, `data/` และ `profiles/` ไม่ได้อยู่ใน git
